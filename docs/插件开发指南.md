# 插件开发指南

本项目是一个“内核 + 插件”的 3D 模型查看器：内核（`core/`）只负责窗口、OBJ 加载和 OpenGL 渲染，其余功能（光照、纹理、Mipmap 过滤、环境映射……）都是独立的插件 DLL。新增功能时**不需要修改内核任何代码**。

## 1. 三步新增一个插件

1. 把 `docs/plugin_template/` 整个目录复制为 `plugins/<插件目录名>/`，把类名、文件名、`pluginId()` 改成自己的。
2. 在 `plugin_config.json` 的 `active_plugins` 数组里加入你的 `pluginId`（数组顺序 = 右侧面板自上而下的顺序）。
3. 重新执行 CMake 配置并编译：

```bat
cmake -S . -B build -G "Visual Studio 18 2026" -A x64 -DCMAKE_PREFIX_PATH=C:/Qt/6.8.3/msvc2022_64
cmake --build build --config Release
```

`plugins/CMakeLists.txt` 会自动扫描每个含 `CMakeLists.txt` 的子目录，DLL 输出到 `build/bin/plugins/`，启动 `viewer3d.exe` 时被 `PluginManager` 自动加载。

**Ubuntu（22.04 及以上，含平板上的 proot 模拟器）**：在项目根目录执行 `bash setup_ubuntu.sh`（国内网络加 `--mirror`），脚本会安装 Qt6/CMake 并编译到 `build-linux/`。之后在图形桌面（VNC / Termux:X11）的终端里用 `./run.sh task1 | task2 | viewer` 启动。Linux 下插件是 `build-linux/bin/plugins/lib*.so`，加载方式与 Windows 相同。新增插件后执行 `cmake --build build-linux` 即可。

## 2. 插件接口（core/PluginInterface.h）

| 函数 | 何时调用 | 用途 |
| --- | --- | --- |
| `pluginId()` | 加载时 | 唯一标识，和 `plugin_config.json` 对应 |
| `pluginName()` / `pluginDesc()` | 任意 | 显示名称、说明 |
| `initialize(ctx)` | 注册时（最先） | 保存 `ViewerContext*` |
| `createUi()` | 注册时 | 返回右侧面板控件，`nullptr` 表示无面板 |
| `onModelLoaded()` | 每次加载 OBJ 后 | 读取 `ctx->currentMesh` / `currentModelPath` |
| `onWindowResize()` | 主窗口缩放 | 重排面板 |
| `onDestroy()` | 程序关闭 | 释放资源、关闭弹出的窗口 |

类声明必须带：

```cpp
class MyPlugin : public QObject, public PluginInterface
{
    Q_OBJECT
    Q_PLUGIN_METADATA(IID PluginInterface_iid)
    Q_INTERFACES(PluginInterface)
    ...
};
```

## 3. 插件能用到的内核能力（ViewerContext）

| 成员 | 说明 |
| --- | --- |
| `viewport` | `GLViewport*`，见下表 |
| `currentMesh` / `currentModelPath` | 当前模型（只读） |
| `appendInfo(text)` | 向底部信息栏输出一行 |
| `loadModel(path)` | 请求内核加载 OBJ（会触发所有插件的 `onModelLoaded`） |
| `dataPath("env")` | 返回 `<exe目录>/data/env`，素材目录 |
| `mainWindow`、`plugins` | 主窗口、已加载的插件列表 |

`GLViewport` 公共接口：

| 分类 | 接口 |
| --- | --- |
| 显示 | `setRenderMode(Surface/Wireframe)`、`setLightingEnabled`、`setLightingCoeffs(a,d,s)` |
| 纹理 | `setTextureImage(QImage)`、`clearTexture()`、`setTextureTiling(n)` |
| Mipmap | `setTextureFilter(TextureUtils::Filter)`、`setMipmapLevelTint(bool)` |
| 环境映射 | `setEnvironmentMap(全景QImage)`（空图=关闭）、`setSkyboxVisible`、`setReflectivity(0~1)` |
| 相机 | `resetCamera()`、`setCameraOrbit(yaw, pitch, distance, target)` |

`TextureUtils`（core/TextureUtils.h）还提供：6 种过滤方式的名称/说明、手动构建 mipmap 链、棋盘格生成、全景图转立方体贴图、列出目录图片等工具函数。

## 4. 约定

- 面板默认按自身高度紧凑堆叠；若希望占满剩余高度（如缩略图列表），对面板调用 `setSizePolicy(QSizePolicy::Preferred, QSizePolicy::Expanding)`。
- 需要复用任务 1/2 的场景控件（`CorridorWidget`、`EnvMapWidget`）时，在插件 CMake 中追加 `target_link_libraries(<target> PRIVATE viewer_scenes)`。
- 新素材直接放进 `data/` 对应目录即可（`data/texture` 纹理、`data/env` 2:1 全景图、`data/corridor/{wall,floor,ceiling}` 走廊贴图、`data/obj` 模型），构建时自动拷贝到 `bin/data`，界面里的列表会自动出现新文件。
- 插件之间不要互相包含头文件，需要协作时通过 `ViewerContext` 或 `GLViewport` 的公共状态。

| `view_toolbar` | plugins/toolbar | 面片/线框切换、退出 |
